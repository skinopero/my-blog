오늘은 CSS로 "어떤 요소를 고를지" 정하는 선택자(selector)를 종류별로 배웠고, 여러 선택자가 겹칠 때 누가 이기는지(우선순위)까지 이어서 배웠다.

## 1. 기본 선택자 — 전체·태그·ID·클래스

```css
* { color: red; }          /* 전체 선택자: 문서 안 모든 요소 */
li { color: blueviolet; }  /* 태그 선택자: 특정 태그 전부 */
#id3 { color: green; }     /* ID 선택자: 고유한 요소 하나 */
.class3 { color: chartreuse; } /* 클래스 선택자: 같은 클래스를 가진 요소들 */
```

ID는 한 문서에서 **하나의 요소만** 가리키도록 유일해야 하고, 클래스는 **여러 요소에 반복해서** 붙일 수 있다는 차이가 있다.

## 2. 속성 선택자 — 대괄호로 조건 걸기

```css
div[name=name2] { background: rgb(77, 164, 235); }      /* 속성값이 정확히 일치 */
div[name~=name1] { background: mediumaquamarine; }      /* 띄어쓰기로 나뉜 값 중 하나 포함 */
div[name^=name] { background: darkseagreen; }           /* 접두사(시작) */
div[class$=class] { background: hotpink; }               /* 접미사(끝) */
div[class*=div] { background: darkslateblue; }           /* 부분 포함 */
```

| 문법 | 의미 |
|---|---|
| `[속성=값]` | 속성값이 정확히 일치 |
| `[속성~=값]` | 띄어쓰기로 구분된 값들 중 하나와 일치 |
| `[속성^=값]` | 값이 그 문자열로 시작 |
| `[속성$=값]` | 값이 그 문자열로 끝 |
| `[속성*=값]` | 값에 그 문자열이 포함 |

## 3. 자손·후손 선택자, 형제(동위) 선택자

```css
#test1 > h4 { background: crimson; }  /* 자손: 바로 한 단계 아래 */
#test1 ul { background: rgb(81,56,10); } /* 후손: 몇 단계든 하위 전부 */

#div-test1 + div { background: aquamarine; } /* 형제: 바로 다음 요소 */
```

`>`는 **자손(바로 아래 자식)**만, 공백은 **후손(모든 하위 단계)**을 고른다는 차이가 핵심이었다. `+`는 같은 부모를 둔 **바로 다음 형제**를 고른다.

## 4. 반응·상태·구조 선택자

```css
#hover-test:hover { background: darkgreen; }   /* 마우스를 올렸을 때 */
#userId:focus { background: hotpink; }          /* 입력창에 포커스됐을 때 */
input[type=checkbox]:checked { width: 100px; }  /* 체크박스가 체크됐을 때 */
option:disabled { background: red; }            /* 비활성화된 요소 */

#test :first-child { background: darkcyan; }     /* 첫 번째 자식 */
#test :last-child { background: rgb(133,48,207); } /* 마지막 자식 */
#test :nth-child(2) { background: lawngreen; }    /* n번째 자식 */
#test2 p:not(:nth-child(odd)) { background: chocolate; } /* 조건의 반대(부정) */
```

사용자의 행동(`:hover`, `:active`)이나 입력 상태(`:checked`, `:disabled`, `:focus`)에 따라 스타일이 달라지는 반응 선택자, 그리고 형제들 사이에서 몇 번째인지로 고르는 구조 선택자(`:nth-child`)까지 한 번에 훑었다.

## 5. 우선순위 — 같은 요소에 여러 스타일이 겹치면?

```css
* { color: red; }
div { background-color: blue; }
#test2 { background-color: mediumpurple; }
.test2 { background-color: orange !important; }
```

```html
<div id="test2" class="test2" style="background-color: green;">우선순위테스트</div>
```

같은 요소에 전체 선택자, 태그 선택자, ID 선택자, 클래스 선택자, 인라인 스타일까지 전부 걸려 있다면 **누가 이길까?**

다섯 살 아이에게 설명한다면: "학교에서 반장, 부반장, 그냥 학생이 서로 다른 말을 하면 누구 말을 들어야 할지 계급 순서가 있는 것처럼, CSS도 '어떤 선택자가 더 힘이 센지' 순서가 정해져 있어. 가장 힘이 센 애가 마지막에 '그래도 내 말이 맞아!(`!important`)'라고 하면 그게 이겨."

![CSS 선택자 우선순위 계급: !important가 가장 강하고, 인라인 스타일 > ID > 클래스 > 태그 > 전체 선택자 순으로 약해진다는 그림]({{ site.baseurl }}/assets/images/2026-09-02-css-specificity.svg)

```
!important > 인라인 선택자 > ID 선택자 > 클래스 선택자 > 태그 선택자 > 전체 선택자
```

위 예제에서는 `.test2`에 `!important`가 붙어 있어서, 인라인 스타일(`style="background-color: green;"`)보다도 `.test2`의 `orange`가 이긴다 — `!important`가 계급 자체를 가장 꼭대기로 끌어올리기 때문이다. `!important` 없이 인라인 스타일만 썼다면 인라인이 이겼을 것이다.

## 오늘의 정리

CSS 선택자는 "전체 → 태그 → 클래스 → ID"처럼 점점 더 좁혀서 요소를 고르는 방법부터, 위치(자손/후손/형제)나 상태(hover/checked/focus)로 고르는 방법까지 다양했다. 여러 선택자가 같은 요소에 겹칠 때는 `!important > 인라인 > ID > 클래스 > 태그 > 전체` 순서로 더 "구체적인" 선택자가 이긴다는 규칙 하나만 기억하면 됐다.

## 더 학습하면 좋은 개념

- **CSS 명시도(Specificity) 점수 계산법** — 오늘은 순서만 외웠는데, 실제로는 ID 개수·클래스 개수·태그 개수를 점수로 환산해서 비교한다. 선택자를 조합했을 때(`div.class#id`) 어떻게 계산되는지 알아두면 좋다.
- **CSS 상속(Inheritance)** — 부모 요소의 스타일 중 일부(색상, 글꼴 등)는 자식에게 자동으로 전달된다. 우선순위와는 별개의 개념이라 헷갈리기 쉽다.
- **`::before`/`::after` 가상 요소** — 오늘 다룬 `:hover` 같은 가상 클래스(콜론 1개)와 달리, 콜론 2개로 쓰는 가상 요소는 실제로 존재하지 않는 요소를 CSS로 만들어낸다.
