  <h1>선물 상자와 일기장 이야기</h1>
  <p class="lead">어제는 건물 안에 방을 여러 개 만들었어요. 오늘은 방 안의 장난감 로봇(컴포넌트)에게 <b>선물</b>을 주고, 로봇이 <b>일기장</b>을 쓰고, 버튼을 누르면 <b>반응</b>하게 만들어요.</p>

<section>
  <h2>1. 엄마가 주는 선물 상자 (props)</h2>
  <p>엄마(부모 컴포넌트)가 로봇(자식)에게 <b>선물 상자</b>를 줘요. <code>&lt;Profile name="이여니" age={25}/&gt;</code>처럼 이름표를 붙여서요. 로봇은 상자를 <b>열어서 쓸 수만</b> 있어요. 내용물을 마음대로 바꾸면 안 돼요(읽기 전용). 숫자나 배열처럼 글자가 아닌 선물은 <code>{}</code>로 감싸서 줘요.</p>
  <div class="pic">
  <svg viewBox="0 0 760 210" role="img" aria-label="부모가 props를 자식에게 전달하고 자식은 읽기만 한다">

<section>
  <h2>2. 내가 고쳐 쓰는 일기장 (state)</h2>
  <p>로봇에게는 <b>일기장</b>도 있어요. 일기장에 적은 값(state)은 로봇이 직접 고칠 수 있어요. 고칠 때는 꼭 <b>고치는 펜(setter)</b>으로 써야 해요. 펜으로 고치면 로봇이 "어, 내용이 바뀌었네!" 하고 <b>화면을 다시 그려요(리렌더링)</b>. 그냥 연필(일반 변수)로 몰래 고치면 로봇은 눈치채지 못해서 화면이 그대로예요.</p>
  <div class="pic">
  <svg viewBox="0 0 760 210" role="img" aria-label="일반 변수는 화면이 안 바뀌고 setter를 쓰면 다시 그려진다">
    <rect x="30" y="30" width="330" height="150" rx="16" class="berry-bg"/>
    <text x="195" y="62" text-anchor="middle" class="t-b">let count = 0</text>
    <text x="195" y="100" text-anchor="middle" class="t-s">값만 몰래 바뀌어요</text>
    <text x="195" y="124" text-anchor="middle" class="t-s">화면은 그대로예요</text>
    <rect x="400" y="30" width="330" height="150" rx="16" class="leaf-bg"/>
    <text x="565" y="62" text-anchor="middle" class="t-b">useState + setCount</text>
    <text x="565" y="100" text-anchor="middle" class="t-s">펜으로 고쳐 쓰면</text>
    <text x="565" y="124" text-anchor="middle" class="t-s">로봇이 화면을 다시 그려요</text>
  </svg>
  </div>
  <p class="cap"><code>const [count, setCount] = useState(0)</code> — 앞은 지금 적힌 값, 뒤는 고치는 펜이에요.</p>
</section>

<section>
  <h2>3. 세 번 눌렀는데 왜 1만 늘까요?</h2>
  <p>로봇은 일기를 쓰는 <b>순간의 사진</b>을 보고 계산해요. 지금 count가 0이면 <code>setCount(count + 1)</code>을 세 번 해도 세 번 다 "사진 속 0에 1을 더해요". 그래서 <b>1</b>이 돼요. 대신 <code>setCount(prev =&gt; prev + 1)</code>이라고 쓰면 "방금 적은 값에 1을 더해줘"라는 뜻이라서 0, 1, 2, 3으로 이어져요.</p>

    <text x="195" y="124" text-anchor="middle" class="t-s">모두 같은 사진(0)을 봐요</text>

<section>
  <h2>4. 버튼을 누르면 반응해요 (이벤트)</h2>
  <p>로봇의 버튼과 입력창에는 <b>"눌리면 이걸 해!"</b>라는 쪽지를 붙여요. 규칙이 세 개예요. 쪽지 이름은 <code>onClick</code>처럼 <b>대문자가 섞인 이름</b>이에요. 쪽지에는 <b>할 일 자체(함수)</b>를 붙여야 해요. <code>handle()</code>이라고 쓰면 쪽지를 붙이는 순간 바로 실행돼요. 그리고 쪽지는 <b>진짜 버튼(button, input)</b>에만 붙어요. 로봇 이름표(컴포넌트)에 붙이면 그냥 선물 상자(props)로 전달만 돼요.</p>
  <div class="pic">

<section>
  <h2>5. 입력창은 로봇이 지켜봐요 (제어 컴포넌트)</h2>
  <p>입력창에 글자를 쓰면, 로봇이 그 글자를 <b>일기장(state)</b>에 바로 적어요. 입력창은 늘 일기장에 적힌 값을 보여줘요. 이름칸과 이메일칸이 있으면 일기장 한 권에 둘 다 적어요. 이름을 쓸 때는 <code>...form</code>으로 <b>기존 내용을 먼저 베껴 쓰고</b> 이름만 바꿔야 해요. 베끼지 않으면 일기장을 통째로 새 걸로 바꿔서 이메일이 사라져요.</p>
  <div class="pic">
  <svg viewBox="0 0 760 210" role="img" aria-label="스프레드로 기존 값을 복사하면 이메일이 남고 안 하면 사라진다">
    <rect x="30" y="20" width="330" height="170" rx="16" class="leaf-bg"/>
    <text x="195" y="50" text-anchor="middle" class="t-b">...form 있음</text>

    <rect x="400" y="20" width="330" height="170" rx="16" class="berry-bg"/>

</section>

<section>
  <h2>6. 번호표를 붙여서 줄 세우기 (map과 key)</h2>
  <p>이름 목록이 있으면 <code>map</code>으로 한 줄씩 그려요. 이때 줄마다 <b>번호표(key)</b>를 붙여야 해요. 누가 새로 오고 누가 빠졌는지 로봇이 알아보려는 거예요. 번호표는 <b>줄 서는 순서(index)</b>가 아니라 <b>그 사람의 고유 번호(id)</b>가 좋아요. 순서로 하면 한 명이 빠질 때 뒤 사람들의 번호가 다 바뀌어요.</p>
  <p>목록을 고칠 때는 원본 종이를 지우개로 고치지 않고 <b>새 종이에 다시 써서</b> 펜(setter)에 넘겨요. 추가는 <code>[...names, 새사람]</code>, 삭제는 <code>filter</code>로 나머지만 옮겨 적어요.</p>
  <div class="pic">
  <svg viewBox="0 0 760 230" role="img" aria-label="스프레드로 추가하고 filter로 삭제하는 새 배열 만들기">

    <text x="195" y="50" text-anchor="middle" class="t-b">추가</text>
    <text x="195" y="90" text-anchor="middle" class="t-c">[...names, {id: nextId, ...}]</text>
    <text x="195" y="128" text-anchor="middle" class="t-s">기존을 베끼고 끝에 새 사람</text>
    <text x="195" y="154" text-anchor="middle" class="t-s">nextId는 +1 해서 겹치지 않게</text>
    <rect x="400" y="20" width="330" height="190" rx="16" class="sun-bg"/>
    <text x="565" y="50" text-anchor="middle" class="t-b">삭제</text>
    <text x="565" y="90" text-anchor="middle" class="t-c">names.filter(n =&gt; n.id !== id)</text>
    <text x="565" y="128" text-anchor="middle" class="t-s">그 번호만 빼고 새 종이에</text>
    <text x="565" y="154" text-anchor="middle" class="t-s">push, splice로 원본은 안 고쳐요</text>
  </svg>
  </div>
</section>

  <div class="term"><b>props</b><small>선물 상자</small>부모가 자식에게 주는 읽기 전용 값. children은 태그 사이의 내용이에요.</div>
  <div class="term"><b>state / useState</b><small>일기장</small>고칠 수 있는 값. setter로 바꾸면 리렌더링돼요.</div>
  <div class="term"><b>prev =&gt; prev + 1</b><small>방금 적은 값 이어받기</small>같은 핸들러에서 여러 번 바꿀 때 누적 계산해요.</div>
  <div class="term"><b>onClick / onChange</b><small>눌리면 해! 쪽지</small>카멜 표기법, 함수를 전달, DOM 요소에만 연결해요.</div>
  <div class="term"><b>제어 컴포넌트</b><small>일기장이 지켜보는 입력창</small>value는 state, onChange에서 state를 바꿔요. [e.target.name]과 ...form을 써요.</div>
  <div class="term"><b>map + key</b><small>번호표 붙여 줄 세우기</small>key는 index보다 고유한 id. 배열 state는 새 배열로 바꿔요.</div>
