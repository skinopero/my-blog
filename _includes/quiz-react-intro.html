1React의 가상 DOM(Virtual DOM)을 가장 알맞게 설명한 것은?
React는 진짜 DOM을 바로 건드리지 않고, 메모리 위에 존재하는 가상 DOM으로 화면을 표현한다. 엘리먼트가 이 가상 DOM을 이루는 조각이다.
2React.createElement('h1', {className:'hi'}, 'helloworld')의 세 인자는 각각 무엇일까?
1번째는 만들려는 요소의 타입(h1, div, pre), 2번째는 프로퍼티, 3번째는 자식 요소다.
3엘리먼트와 컴포넌트의 관계로 맞는 것은?
엘리먼트는 요소 노드, 어트리뷰트 노드, 텍스트 노드로 구성된 가장 작은 단위이고, 컴포넌트는 그 엘리먼트를 반환하는 개념이다. 오늘 배운 함수형 컴포넌트는 함수로 만든다.
4브라우저는 JSX를 이해하지 못한다. 오늘 실습에서 이 문제를 어떻게 해결했을까?
Babel이 JSX를 일반 JavaScript로 바꿔준다. head에 Babel 관련 script를 추가하고, JSX를 쓰는 script 태그에 type="text/babel"을 넣는다.
5React에서 HTML의 class 대신 className을 쓰는 이유는?
createElement의 프로퍼티와 JSX는 JavaScript 문법 안에서 쓰이므로 예약어인 class 대신 className을 쓴다.
6컴포넌트 이름을 소문자로 시작해서 <header/>처럼 쓰면 어떻게 될까?
앞글자가 대문자여야 컴포넌트로 인식한다. 대문자 규칙은 단순한 관습이 아니라 React가 컴포넌트와 HTML 태그를 구분하는 기준이다.
7<h1>...</h1><h3>...</h3>처럼 같은 레벨 요소를 연달아 반환하면 문법 에러가 난다. div 대신 Fragment(<> </>)를 쓰는 이점은?
반환할 수 있는 최상위 요소는 하나여야 한다. div로 감싸면 불필요한 div 영역이 생기지만, Fragment는 DOM에 흔적을 남기지 않는다.
8style={{ border: '1px solid black' }}에서 중괄호가 두 겹인 이유는?
바깥 {}는 "여기부터 JavaScript 표현식"이라는 JSX의 표시이고, 안쪽 {}는 스타일 객체 리터럴 자체다.
