1List는 순서와 중복을 각각 허용하는가?
List는 index로 순서를 유지하고, 같은 값을 여러 번 넣는 것도 허용해.
2Set은 순서와 중복을 각각 허용하는가?
Set은 저장 순서를 유지하지 않고, 같은 요소를 중복해서 저장하지 않아.
3List와 Set 같은 인터페이스로 직접 객체를 생성할 수 있는가?
인터페이스는 생성자가 없어서 직접 객체를 만들 수 없어. List는 ArrayList, Set은 HashSet처럼 구현한 클래스로 만들어야 해.
4DTO(Data Transfer Object)의 역할은?
DTO는 필드, 생성자, getter/setter, toString으로 이루어진, 데이터를 운반하기 위한 클래스야.
5향상된 for문(enhanced for)의 형식은?
향상된 for문은 인덱스를 직접 세지 않고, 컬렉션 안의 값을 하나씩 꺼내서 변수에 담아줘.
6HashSet에 "jpa"를 이미 넣은 상태에서 "jpa"를 또 add()하면?
Set은 중복을 허용하지 않아서, 같은 값을 또 넣어도 그냥 무시되고 1개만 남아.
7TreeSet이 HashSet과 다른 점은?
TreeSet도 중복은 허용 안 하지만, 추가로 이진 검색 트리 구조라서 데이터가 항상 정렬된 상태로 유지돼.
8(int)(Math.random() * 45) + 1이 만들어내는 범위는?
Math.random()은 0 이상 1 미만이라 *45하면 0~44.99..., (int)로 0~44가 되고, +1로 최종 1~45 범위가 돼.
