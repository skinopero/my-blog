1"apple".concat("mango")의 결과는?
concat()은 두 문자열을 이어 붙인 새 문자열을 반환해. 길이를 구하는 건 length()야.
2"abc".charAt(1)의 결과는?
인덱스는 0부터 시작해. 0번이 'a', 1번이 'b', 2번이 'c'야.
3String str1 = "java"; String str3 = "java";처럼 둘 다 리터럴로 만들었을 때, str1 == str3은?
리터럴로 만든 문자열은 같은 문자열 풀(pool) 공간을 가리켜서 == 비교가 true가 돼.
4String str2 = new String("java"); String str4 = new String("java");일 때, str2 == str4는?
new는 항상 새로운 공간을 만들기 때문에, 값이 같아도 str2와 str4는 서로 다른 객체야.
5생성 방식과 상관없이 문자열의 "값"만 비교하고 싶을 때 쓰는 메소드는?
equals()는 리터럴이든 new로 만들었든 상관없이 값만 비교해줘.
6int[] iarr = new int[5]; 직후, iarr[1]의 값은?
heap은 빈 칸을 허용하지 않아서, JVM이 int 배열의 각 칸을 기본값 0으로 미리 채워둬.
7클래스의 필드(참조형)를 아무것도 대입하지 않고 바로 출력하면 기본값은?
참조형 필드(String 등)의 기본값은 null이야. int 같은 정수형만 0이 기본값이고.
8클래스 안에 매개변수가 있는 생성자를 직접 작성하면, 매개변수 없는 기본 생성자는 어떻게 되나?
매개변수가 있는 생성자를 하나라도 직접 작성하면, 컴파일러는 기본 생성자를 더 이상 자동으로 만들어주지 않아. 필요하면 직접 추가해야 해.
