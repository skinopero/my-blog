1const cartRef = cart; 뒤에 cartRef.push('파스타')를 하면 cart는 어떻게 될까?
대입(=)은 값을 복사하는 게 아니라 같은 객체의 주소를 복사한다. const는 변수에 다른 값을 다시 대입하는 것만 막고, 배열 내부를 바꾸는 것은 막지 않는다.
2const cartCopy = [...cart];를 정확히 부르는 이름과 특징은?
스프레드는 새 객체를 만들지만 한 단계까지만 복사한다. 안쪽에 또 객체나 배열이 있으면 그건 같이 공유된다.
3객체 구조 분해 const {name, price} = menu;에서 반드시 지켜야 하는 것은?
객체는 순서가 아니라 key 이름으로 꺼낸다. key에 없는 이름을 쓰면 undefined가 된다. 배열 구조 분해는 반대로 순서(인덱스)로 꺼낸다.
4getElementsByTagName('li') 결과에 forEach, map 같은 배열 메서드를 쓰려면?
HTMLCollection은 유사 배열이라 배열 전용 메서드가 없다. $는 DOM 요소를 담은 변수라는 표시용 관례일 뿐이다.
5$btn.onclick = ...을 두 번 대입하면 어떻게 될까?
프로퍼티 방식은 이벤트당 핸들러 하나만 가진다. 여러 개를 등록하려면 addEventListener를 쓴다.
6removeEventListener로 핸들러를 제거하려면?
모양이 같아도 새로 만든 익명 함수는 다른 객체라서 제거되지 않는다. 그래서 제거할 핸들러는 이름 있는 함수로 정의해 두고 같은 참조를 넘긴다.
7onclick="handleClick1()"의 함수 안 this와 onclick="handleClick2(this)"로 넘긴 인자는 각각?
일반 함수로 호출하면 this는 전역 객체 window다. 호출할 때 this를 인자로 직접 넘기면 이벤트가 걸린 요소를 받을 수 있다.
8텍스트 칸에 입력하는 글자 수를 입력할 때마다 즉시 세려면 어떤 이벤트가 알맞을까?
텍스트 입력의 change는 포커스를 잃어야 발생한다. input은 붙여넣기나 음성 입력에도 즉시 반응한다.
