1NullPointerException은 언제 발생할까?
참조 변수가 가리키는 대상이 없는(null) 상태에서 그 변수를 통해 뭔가를 하려고 할 때 발생하는 런타임 예외야.
2session.getAttribute("loggedInUser")의 반환 타입은?
어떤 타입이든 담을 수 있도록 Object로 반환하기 때문에, 실제 타입을 안다면 (String)처럼 명시적으로 형변환해서 꺼내 써야 해.
3서블릿 코드 안에서 처리되지 않은 예외가 그대로 터지면, 컨테이너는 보통 어떤 상태 코드로 응답할까?
처리되지 않은 예외는 서버 쪽 문제로 간주되어 500 Internal Server Error로 변환돼.
4req.getSession(false)의 의미는?
getSession(false)는 기존 세션이 없으면 null을 돌려줘. 이걸 모르고 바로 .getAttribute()를 호출하면 NPE가 날 수 있어.
5세션이 없는 상태로 /auth에 요청이 왔을 때, LoginFilter가 하는 일은?
LoginFilter가 세션·로그인 정보를 먼저 확인해서, 없으면 아예 서블릿까지 가지 못하게 걸러줘 — 이게 AuthServlet의 NPE를 실제로 막아주는 안전장치야.
6필터는 서블릿보다 먼저 실행될까, 나중에 실행될까?
필터는 HTTP 요청이 서블릿에 도달하기 전에 동작하도록 설계된 컴포넌트야.
7폼을 POST로 제출해 /cookie에 요청하면 doPost()가 호출되는데, 그 안에서 화면을 보여주기 위해 재사용하는 메서드는?
doPost()가 쿠키를 설정한 뒤 doGet(req, resp)를 직접 호출해서, 쿠키를 보여주는 화면 로직을 재사용해.
8서블릿 컨테이너가 doGet()과 doPost() 중 무엇을 호출할지 결정하는 기준은?
service()가 요청의 HTTP 메소드를 보고 자동으로 doGet 또는 doPost를 호출해줘.
