1JDBC(Java DataBase Connectivity)란?
JDBC는 Java 코드가 DB에 접근할 수 있게 해주는 표준 프로그래밍 API야.
2java.sql 패키지 자체가 정의하는 것은?
java.sql은 DriverManager, Connection, Statement, ResultSet 같은 인터페이스(약속)만 정의하고, 실제 통신 구현은 DBMS별 드라이버가 맡아.
3DBMS를 MySQL에서 Oracle로 바꾼다면, Java 코드는 어떻게 될까?
java.sql 인터페이스는 표준이고, 실제 번역(통신)은 드라이버가 담당하기 때문에 DBMS가 바뀌어도 Java 코드는 거의 그대로 두고 드라이버만 바꾸면 돼.
4IntelliJ에서 한글이 깨지지 않도록 가장 먼저 설정한 항목은?
한글 데이터를 다루므로 인코딩이 맞지 않으면 조회·저장 시 글자가 깨질 수 있어서, 프로젝트 시작 시 UTF-8로 맞춰둬.
5오늘 mvnrepository에서 찾아 사용한 MySQL Connector/J 버전은?
오늘 설치한 MySQL Connector/J는 8.4.0 버전이야.
6mvnrepository에서 복사한 Gradle 의존성 코드를 추가하는 파일은?
build.gradle의 dependencies 블록에 추가하고 Gradle Sync를 한 번 더 해줘야 실제로 라이브러리가 받아져.
7IntelliJ Database 툴에서 접속 정보를 입력한 뒤 연결을 확인하는 버튼은?
Host, Port, User, Password를 입력한 뒤 Test Connection으로 연결이 되는지 확인하고, 성공하면 OK로 저장해.
8Test Connection이 실패했을 때 가장 먼저 확인해야 할 것이 아닌 것은?
연결 테스트 실패는 보통 DB 실행 여부, 계정 권한, 주소·포트 설정 문제야. 테마 색상과는 관련이 없어.
